# DSA-Progress

Daily DSA practice by Prakhar Sonker 🚀

## 📂 Structure
- `topic-wise/<Topic>/` — code files and notes, organized by topic.
- Each problem has:
    - a code file (`.java`, `.py`, `.cpp`, etc.)
    - an optional markdown notes file with approach & dry-run.

## 📝 How I Add Problems
1. Create code file in the correct topic folder.
2. Add a `.md` notes file with problem link, approach, complexities, edge-cases.
3. Commit with message: `Day N (YYYY-MM-DD): Problem Name (Platform #)`
